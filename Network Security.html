3 Key Tips for Home Network Security

Top takeaways from 12-hour training to increase security

1 Secure the Modem

Ensure the modem's administrative login is changed from the factory default to a strong, unique password. Disable any vendor remote-login features you do not need and keep modem firmware updated to reduce the attack surface at your network edge.

Quick wins: change default password, disable remote admin, enable auto-updates (if available).

2 Wi-Fi Segmentation

Create seperate networks for trusted devices (primary) Wi-Fi network and guest or IoT devices on separate network(s). This prevents less-secure gadgets from reaching sensitive systems.

Quick wins: create separate SSIDs (Primary vs Guest/IoT) and use highest sercurity protocol possible (e.g. WPA3)

3 Port & Traffic Isolation

Consider upgrading unmanaged switch to a managed switch. Use VLANs to map subnets (e.g. 10=Work, 20=Home, 30=Shared, 40=IoT) and port isolation to separate traffic (Work / Home / Shared / IoT) and isolate ports.

Recommendation: Learn about upgrading to a managed switch if using unmanaged switch.
